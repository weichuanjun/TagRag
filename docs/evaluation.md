# 评测

TagRAG 的主张必须用数据来证明：**标签体系到底有没有提升检索质量？** 仓库内置了一个评测脚本，在同一套问题上对比两种检索模式：

- `hybrid`：稠密 + BM25 混合检索，不使用标签
- `hybrid+tags`：在混合检索的基础上，加上标签通道和标签加权

## 准备问题集

`eval.jsonl` 每行一个样本，命中条件二选一：

```json
{"query": "一线城市住宿标准是多少", "expected_doc": "差旅报销制度.md"}
{"query": "年假几天", "expected_text": "5天带薪年假"}
```

建议按以下几层准备 60–100 道题，并分层统计结果：

| 层 | 例子 | 要看什么 |
|---|---|---|
| 单文档事实 | 「住宿上限多少」 | 能否命中 |
| 跨章节 / 跨文档 | 「报销和采购的审批人有什么不同」 | 召回是否全面 |
| 同义改写 | 用别名或口语提问 | 标签别名有没有起作用 |
| 无答案 | 知识库里没有的问题 | 是否正确判为 `sufficiency=none` 并拒答 |
| 越权 | 用低权限用户组提问 | ACL 有没有泄漏 |

问答页面上的 👎 反馈会记录在 `query_logs` 表里，可以定期整理进问题集。

## 运行

```bash
python backend/scripts/evaluate.py --kb 1 --data eval.jsonl --k 5
```

输出两种模式各自的 Hit@5 和 MRR，并列出没有命中的问题。
